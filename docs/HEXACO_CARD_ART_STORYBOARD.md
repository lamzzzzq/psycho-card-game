# HEXACO 人格牌美术分镜 · 生图前定稿稿

> 范围：HEXACO-60 的 60 张人格牌插画。此文定义角色连续性、场景边界和逐题画面；它不是最终 ImageGen prompt 清单，确认后才扩写为可批量执行的 prompt。
>
> 题号、维度和正反向均以 `src/data/hexaco-questions.ts` 为真相源。画面只呈现题意的一个日常瞬间，不给人格倾向贴好坏标签。

## 1. 继承与扩展

沿用既有 Big Five 角色稿的基础：1024×1024、图中无字无框、主体居中且四周留约 10% 安全边、可爱而年轻的软黏土／毛毡质感微缩风格、哑光材质、**明亮高调的奶油白自然光**、低对比且几乎无暗角。CSS 负责卡框、文字和维度色，插画不要自行绘制塔罗边框、星点、文字或 UI。

本轮不再把人物固定在家中。角色应像生活在同一座温暖现代城市中的两位年轻成年人：能在家、街道、公共交通、学校、办公室、文化场馆、户外与朋友聚会间自然活动。

## 2. 角色连续性与有限衣橱

| 角色 | 固定识别点 | 可变化服装 |
|---|---|---|
| 女性主角 | **完全沿用旧稿**：浅暖桃肤色、深色及肩大波浪软发束与侧分、较大的竖向黑椭圆眼、细小鼻嘴、年轻可爱的圆润比例 | 陶土红帽衫（居家/休闲锚点）；只可增加不遮挡发型和脸部的简洁场景外层 |
| 男性主角 | **完全沿用旧稿**：浅暖桃肤色、蓬松的黑色短发（宽大的圆润发束与固定轮廓）、较大的竖向黑椭圆眼、细小鼻嘴、年轻可爱的圆润比例 | 深绿色帽衫（居家/休闲锚点）；只可增加不遮挡发型和脸部的简洁场景外层 |

- 奇数题默认女性、偶数题默认男性，沿用旧牌组的可预测性；只有构图连续性明显受损时才允许调整。
- 发型轮廓、肤色、眼睛形状、脸型比例与视觉年龄是**不可变锚点**，不因地点或服装而改变；人物应像旧稿角色走进新场景，而非新设计的人物。
- 禁止电影感暗调、棕色滤镜、强阴影、暗角与写实成熟比例；背景以明亮象牙/奶油白为主，阴影轻且浅。
- 场景需要配角时，配角是模糊的日常人物，不要抢占主体；不要求所有牌都有第二主角。
- 同一人物可以在不同牌中换装，但每种服装需重复出现，让人感觉是“有限衣橱”，不是每张换了一个人。
- 情绪以姿势、视线、手势和场景线索表达。避免夸张哭脸、愤怒脸、反派脸或道德审判式表情。

## 3. 场景与敏感题规则

- 文化与学习：美术馆、音乐厅、图书馆、讲座、书店、工作室。
- 组织与工作：书桌、共享办公室、工作坊、车站行前、厨房备餐。
- 社交与关系：小型聚会、社团讨论、咖啡馆、搬家/送别、社区活动。
- 户外与情绪：雨天门厅、月台、低风险步道、诊所等候区、安静的家。
- 金钱、贿赂、盗窃、伪钞等题：只画“有诱惑或选择的瞬间”，不画犯罪实施、不画可复制的犯罪细节，也不把高低分倾向画成恶人或英雄。
- 负向题不必都画失败或孤独；它们应与正向题同样温和、可信、尊重人。

## 5. 试生建议（先做 6 张）

先用 1、2、3、4、5、6 做小样：它们正好覆盖 O/C/A/X/E/H，也同时验证美术馆、书桌、咖啡馆、居家、雨天与办公室六类场景。验收重点是“仍看得出同一男一女”与“每张场景一眼可读”，而不是一次做完所有细节。

通过后，再把每条分镜扩写为统一 prompt：`风格锁定 + 角色锁定 + 当题场景与动作 + 构图限制 + 禁止项`。
